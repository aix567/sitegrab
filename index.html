Capabilities

The whole workflow, one button.

Static pages, JavaScript, paginated listings, product catalogs, sitemaps, CSS-referenced assets — all crawled, saved, and rewritten so the output works offline.

01 / MIRROR

Recursive crawl

Same-domain. Follows links, forms, sitemaps. Saves HTML, CSS, JS, images, fonts, video, docs. Handles lazy-loaded images and srcset.

02 / REWRITE

Offline link rewriting

Every absolute URL becomes a relative local path. Disconnect Wi-Fi, open index.html, everything still works.

03 / WALK

Pagination exhaustion

Detects ?page=N, ?offset=N, ?start=N and walks each key up to 500 pages. Search backends crawled to exhaustion.

04 / EXTRACT

Product harvest

Reads JSON-LD and OpenGraph from every page. Writes _products.ndjson. Query it with a small filter language built into the app.

05 / SCAN

Exposed-data hunter

23 rules scan the mirror for AWS keys, JWTs, Stripe secrets, .env leaks, .git/ exposures, admin panels, GraphQL endpoints, and more.

06 / RESUME

Crash-safe state

Writes crawl state after every batch. Kill the process mid-run, relaunch, it picks up exactly where it left off.

Exposed-data hunter

Every secret redacted in the output.

The scan finds credentials, misconfigurations, and admin surfaces. Every match is truncated to first-6 / last-6 characters in the report. Enough to confirm a real hit, not enough to use it.
